# Praktik HTML Dasar — Website Resep

Proyek ini merupakan praktik setelah menyelesaikan tutorial HTML dasar.

## Tugas

Membuat sebuah **website resep** hanya menggunakan HTML dasar yang telah dipelajari selama tutorial.

Akan terus diperbaharui seiring dengan bertambahnya tutorial yang diselesaikan
 sudah nambah css, masih halaman utama

## Materi yang Telah Dipelajari

Sejauh yang saya ingat, beberapa materi HTML yang telah dipelajari dan akan digunakan dalam proyek ini meliputi:

* Membuat dokumen HTML
* Struktur direktori
* Struktur dasar HTML
* Membuat `<head>` dan `<body>`
* Heading
* Paragraf
* Styling teks menggunakan `<strong>` dan `<em>`
* Ordered list dan unordered list
* Link
* Menampilkan gambar menggunakan `<img>`
* Membuat file utama `index.html`

Kemungkinan masih ada beberapa materi yang belum saya cantumkan. Daftar ini akan saya lengkapi seiring proses pengerjaan proyek.

Untuk CSS yang paling saya ingat

* display flex
* justify-content
* buat card
* flexbox
* hover


## Kesulitan yang Dihadapi

Kesulitan saya saat ini lebih banyak berada pada penggunaan **Git**.

Beberapa perintah Git sudah cukup saya ingat dan pahami penggunaannya:

* `git clone`
* `git add`
* `git commit`
* `git status`
* `git log`

Sementara itu, beberapa perintah masih belum terlalu saya hafal, terutama:

* `git pull`
* `git push` 14/09/26 push udah bisa

Saya juga belum terlalu memahami alur ketika bekerja dengan **branch**, melakukan **merge**, atau ketika terjadi konflik (*merge conflict*). Untuk saat ini, saya masih perlu melihat kembali dokumentasi atau referensi ketika menghadapi situasi tersebut.

## Tujuan Praktik

Melalui proyek ini, saya ingin memperkuat pemahaman HTML dasar sekaligus mulai membiasakan diri menggunakan Git dan GitHub dalam proses pengembangan proyek.

Saya tidak menargetkan website yang kompleks. Fokus utama proyek ini adalah **mempraktikkan materi yang telah dipelajari dan memahami alur kerja dasar dari membuat proyek hingga menyimpannya menggunakan Git dan GitHub**.
